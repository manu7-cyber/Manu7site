# ARK VISUALS website

This folder is intended to be uploaded as `arkvisuals/` inside the existing GitHub Pages repository.

## Files
- `index.html` — website structure and content
- `style.css` — responsive dark luxury styling
- `script.js` — intro animation, mobile menu, reveal animations and WhatsApp enquiry form
- `assets/logo/ark-logo.png` — add the original ARK VISUALS logo here
- `assets/portfolio/` — add real portfolio media here when ready

## Publish in the existing repository
1. Open your existing repository: https://github.com/Manu7-cyber/Manu7site
2. Do not edit or replace the existing root `index.html` (your wedding invitation).
3. Upload the complete `arkvisuals` folder into the repository root.
4. Commit the changes.
5. Open: https://manu7-cyber.github.io/Manu7site/arkvisuals/

## Before publishing
- The original ARK logo is already included at `assets/logo/ark-logo.jpg`.
- Add only genuine project images/videos to `assets/portfolio/` and then we can build the portfolio gallery.
